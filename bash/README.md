# Bash

Bash is a Unix shell and command language derived from the Bourne shell. It supports interactive use and scripting and adds features beyond POSIX `sh`, including arrays, `[[ ... ]]`, richer parameter expansion, and extended shell syntax.

The [Wikipedia article on Bash](https://en.wikipedia.org/wiki/Bash_(Unix_shell)) describes it as created in 1989 by Brian Fox for the GNU Project as a free software replacement for the Bourne shell, supported by the Free Software Foundation. It became the default login shell on many Linux distributions and can run both interactively and non-interactively, the latter by executing shell scripts.
