# Dart

Dart is a statically typed general-purpose programming language designed for client application development. It supports both just-in-time and ahead-of-time compilation and is closely associated with Flutter while also supporting command-line, server, and web programs.

According to [Wikipedia](https://en.wikipedia.org/wiki/Dart_(programming_language)), Dart was designed by Lars Bak and Kasper Lund at Google and unveiled at the GOTO conference in Aarhus, Denmark, in October 2011. It is an object-oriented, class-based, garbage-collected language that can compile to native machine code, JavaScript, or WebAssembly, and it underlies the Flutter application framework.
