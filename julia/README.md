# Julia

Julia is a high-level programming language designed particularly for numerical, scientific, and technical computing. It combines dynamic programming with multiple dispatch and specializes code at runtime to generate native machine code through LLVM.

The [Wikipedia article on Julia](https://en.wikipedia.org/wiki/Julia_(programming_language)) explains that Jeff Bezanson, Stefan Karpinski, Viral B. Shah, and Alan Edelman began work on the language in 2009 with the goal of a free language that was both high-level and fast, publicly announcing it in February 2012. Julia relies on multiple dispatch, selecting which method to call based on the types of all of a function's arguments, rather than the single dispatch used by most object-oriented languages.
