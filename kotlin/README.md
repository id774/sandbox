# Kotlin

Kotlin is a statically typed general-purpose programming language with strong interoperability with Java and the Java Virtual Machine ecosystem. It adds features such as null-safety, concise data types, extension functions, coroutines, and support for multiple compilation targets.

As described on [Wikipedia](https://en.wikipedia.org/wiki/Kotlin_(programming_language)), Kotlin was unveiled by JetBrains in July 2011 after a year of development and open-sourced under the Apache 2 license in February 2012, taking its name from Kotlin Island near Saint Petersburg. It targets the JVM by default but can also compile to JavaScript or, via LLVM, to native code, and Google named it a preferred language for Android development in 2019.
