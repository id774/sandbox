# Graphviz DOT

DOT is a declarative graph description language used by Graphviz to describe nodes, edges, subgraphs, and their attributes. Graphviz layout engines interpret DOT descriptions to compute graph geometry and render the result into visual output formats.

The [Wikipedia article on the DOT language](https://en.wikipedia.org/wiki/DOT_(graph_description_language)) explains that it was developed as part of the Graphviz project and defines a graph's structure without itself providing any facilities for rendering it; separate programs such as Graphviz's own layout engines read a DOT description and render it into formats such as SVG, PDF, or PNG.
