# Scheme (Gauche)

Scheme is a minimalist Lisp-family programming language built around lexical scope, first-class procedures, recursion, and a small core language. Gauche is a Scheme implementation oriented toward practical scripting and extension while retaining the language's functional and macro-based programming model.

According to Wikipedia, [Scheme](https://en.wikipedia.org/wiki/Scheme_(programming_language)) was created in the 1970s at the MIT Computer Science and Artificial Intelligence Laboratory by Guy L. Steele and Gerald Jay Sussman and was the first Lisp dialect to adopt lexical scope and require tail-call optimization. [Gauche](https://en.wikipedia.org/wiki/Gauche_(Scheme_implementation)), primarily developed by Shiro Kawai, is an R7RS Scheme implementation aimed at scripting in production environments, with quick startup, a built-in system interface, and native multilingual support among its design goals.
