# C#

C# is a statically typed, managed programming language for the .NET platform. It combines object-oriented programming with features such as generics, delegates, LINQ, asynchronous programming, and automatic memory management.

The [Wikipedia article on C#](https://en.wikipedia.org/wiki/C_Sharp_(programming_language)) attributes its design to Anders Hejlsberg, Scott Wiltamuth, and Peter Golde at Microsoft, first widely distributed in July 2000 and later standardized by Ecma and ISO/IEC. Its name references the musical sharp symbol, indicating a semitone higher in pitch than C, and the language is tightly integrated with the .NET Common Language Runtime.
