# Elixir

Elixir is a dynamically typed functional programming language that runs on the Erlang virtual machine. It uses the BEAM process model for lightweight concurrency and fault isolation while adding macros, protocols, and a syntax distinct from Erlang.

As described on [Wikipedia](https://en.wikipedia.org/wiki/Elixir_(programming_language)), Elixir builds on top of Erlang and shares its abstractions for building distributed, fault-tolerant systems, while adding compile-time metaprogramming through macros and polymorphism through protocols. It draws influences from Ruby, Erlang, and Clojure, and is often applied in telecommunications, e-commerce, and finance.
