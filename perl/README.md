# Perl

Perl is a dynamically typed general-purpose scripting language with strong facilities for text processing and regular expressions. It supports procedural, object-oriented, and functional styles and has traditionally been used for automation, system administration, data transformation, and web-related tasks.

The [Wikipedia article on Perl](https://en.wikipedia.org/wiki/Perl) notes that Larry Wall released version 1.0 in December 1987 as a general-purpose Unix scripting language intended to make report processing easier, with Perl 5, first released in 1994, remaining the current major version. It gained widespread popularity in the mid-1990s as a CGI scripting language, owing much of that to its regular expression and string-parsing abilities, and has since been nicknamed "the Swiss Army chainsaw of scripting languages."
