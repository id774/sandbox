# Zsh

Zsh is a Unix shell and command language compatible with much of the Bourne-style shell model while providing additional scripting and interactive features. It includes arrays, advanced parameter expansion and globbing, programmable completion, and extensive interactive customization.

The [Wikipedia article on the Z shell](https://en.wikipedia.org/wiki/Z_shell) states that Paul Falstad created it in 1990 as a student at Princeton University, naming it after a teaching assistant, Zhong Shao, whose login "zsh" he thought made a good shell name. It largely preserves the Bourne shell's syntax while deviating from the POSIX standard in some ways and combining features from ksh and tcsh, such as programmable completion, extended globbing, and themeable prompts, and it is the default interactive shell on macOS.
