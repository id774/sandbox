# C++

C++ is a compiled, statically typed, multi-paradigm programming language that combines low-level control with higher-level abstractions. It supports procedural and object-oriented programming together with templates, generic programming, RAII, and direct resource management.

The [Wikipedia article on C++](https://en.wikipedia.org/wiki/C%2B%2B) describes it as created by Bjarne Stroustrup, who began developing it at Bell Labs in 1979 as an extension of C with object-oriented features, first released in 1985. The name, suggested by Rick Mascitti, refers to C's `++` increment operator, and the language has since been standardized and revised repeatedly by ISO.
