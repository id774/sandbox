# Lua

Lua is a lightweight, dynamically typed programming language designed to be embedded in other applications as well as used for standalone scripting. Its core data model is centered on tables, first-class functions, lexical closures, and a small portable runtime.

According to [Wikipedia](https://en.wikipedia.org/wiki/Lua), Lua originated in 1993 at Tecgraf, growing out of earlier data-description and configuration languages developed there to add flexibility to projects for the Brazilian company Petrobras; its name is Portuguese for "moon." The reference implementation is written in ANSI C, and its only native data structure, the table, stands in for the arrays, sets, lists, and records that other languages provide as separate types.
