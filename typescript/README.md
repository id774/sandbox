# TypeScript

TypeScript is a programming language that extends JavaScript with a static type system and compile-time tooling. Its type information is removed when producing JavaScript, allowing TypeScript programs to use the JavaScript runtime and ecosystem while adding type checking and richer editor support.

The [Wikipedia article on TypeScript](https://en.wikipedia.org/wiki/TypeScript) describes it as developed by Microsoft as free and open-source software under the Apache License 2.0, adding optional static typing to JavaScript for building large applications. Because it is a superset of JavaScript, existing JavaScript can be incorporated into a TypeScript program directly, and its compiler can target ECMAScript 5 and above, transpiling newer language features down to older equivalents.
