# C

C is a compiled, procedural systems programming language that provides direct memory access through pointers and a small runtime model. It is commonly used for operating systems, embedded software, libraries, and other software where low-level control and portability matter.

As described in the [Wikipedia article on C](https://en.wikipedia.org/wiki/C_(programming_language)), the language was created in 1972 by Dennis Ritchie at Bell Labs as a successor to the B programming language. It has been standardized since 1989 by ANSI and later jointly by ISO and IEC, and remains widely used to implement operating system kernels, device drivers, and embedded systems.
