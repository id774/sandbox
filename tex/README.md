# TeX

TeX is a typesetting system and macro programming language designed for precise control over document layout, especially mathematical and technical material. Documents are expressed through commands and macros that the TeX engine expands and typesets, and TeX forms the foundation for higher-level formats such as LaTeX.

According to [Wikipedia](https://en.wikipedia.org/wiki/TeX), Donald Knuth designed and wrote TeX, first releasing it in 1978 out of frustration with the typesetting quality available for the second edition of his book series The Art of Computer Programming. Alongside the companion Metafont system for font construction, TeX became widely used in academia, especially in mathematics, computer science, physics, and other technical fields.
