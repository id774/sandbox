# Erlang

Erlang is a dynamically typed functional programming language designed for concurrent, distributed, and fault-tolerant systems. It runs on the BEAM virtual machine and uses lightweight isolated processes and message passing as its primary concurrency model.

The [Wikipedia article on Erlang](https://en.wikipedia.org/wiki/Erlang_(programming_language)) traces its origins to proprietary work at Ericsson by Joe Armstrong, Robert Virding, and Mike Williams in 1986, released as free and open-source software in 1998. Its "let it crash" philosophy favors restarting a failed process outright over attempting to recover from an error, and processes communicate exclusively through message passing rather than shared memory.
