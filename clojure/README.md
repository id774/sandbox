# Clojure

Clojure is a dynamically typed Lisp dialect that runs primarily on the Java Virtual Machine. It emphasizes immutable persistent data structures, first-class functions, macros, and explicit approaches to concurrent state while providing direct interoperability with Java.

The [Wikipedia article on Clojure](https://en.wikipedia.org/wiki/Clojure) notes that Rich Hickey began working on the language in 2005 and released it publicly in October 2007, naming it as a play on the word "closure" incorporating letters from C#, Lisp, and Java, the three languages that most influenced its design. Clojure advocates immutable data structures and explicit approaches to managing state to make concurrent programs simpler and more robust.
