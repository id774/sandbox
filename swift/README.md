# Swift

Swift is a statically typed, compiled general-purpose programming language designed with an emphasis on safety and performance. It provides optionals, value types, protocols, generics, automatic reference counting, and interoperability with the Apple platform ecosystem.

The [Wikipedia article on Swift](https://en.wikipedia.org/wiki/Swift_(programming_language)) states that Chris Lattner began developing the language at Apple in July 2010 as an eventual replacement for Objective-C, first releasing it in June 2014 alongside Xcode 6. Apple made it open source under the Apache License 2.0 in December 2015, and it was designed to preserve core Objective-C concepts such as dynamic dispatch while catching more software bugs at compile time.
