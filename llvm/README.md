# LLVM IR

LLVM Intermediate Representation is a typed, low-level intermediate language used inside compiler pipelines rather than primarily as an application programming language. Its static single-assignment form provides a common representation between compiler front ends, optimization passes, and machine-code back ends.

The [Wikipedia article on LLVM](https://en.wikipedia.org/wiki/LLVM) credits Chris Lattner and Vikram Adve with designing and developing the project starting in 2001, work for which they later received the 2012 ACM Software System Award. LLVM provides a set of reusable, modular compiler and toolchain libraries built around a frontend-agnostic, portable intermediate representation in static single-assignment form, making it a common foundation for building compiler frontends and backends for many languages and architectures.
