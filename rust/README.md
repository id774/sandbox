# Rust

Rust is a statically typed systems programming language designed to provide memory safety and concurrency safety without requiring a garbage collector. Its ownership and borrowing model manages resource lifetimes at compile time while supporting low-level control and zero-cost abstractions.

The [Wikipedia article on Rust](https://en.wikipedia.org/wiki/Rust_(programming_language)) traces the language to a personal project Graydon Hoare began in 2006, which Mozilla Research began sponsoring in 2009 before publicly releasing it in 2010 and reaching version 1.0 in 2015. Rust is syntactically similar to C++ but guarantees memory safety without a garbage collector, drawing on ideas from functional languages such as immutability, higher-order functions, and pattern matching alongside object-oriented features like structs, enums, and traits.
