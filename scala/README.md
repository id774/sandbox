# Scala

Scala is a statically typed general-purpose programming language for the Java Virtual Machine that combines object-oriented and functional programming. It provides Java interoperability together with features such as higher-order functions, pattern matching, immutable data structures, and an expressive type system.

According to [Wikipedia](https://en.wikipedia.org/wiki/Scala_(programming_language)), Martin Odersky began designing Scala in 2001 at the École Polytechnique Fédérale de Lausanne, with the name a portmanteau of "scalable" and "language." It compiles to JVM bytecode by default but can also transpile to JavaScript via Scala.js or compile to a native executable through Scala Native, and it combines object-oriented programming with functional-language features such as currying, immutability, lazy evaluation, and pattern matching.
