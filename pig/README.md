# Pig Latin

Pig Latin is a high-level data-flow language used by Apache Pig to express transformations over large datasets. Programs describe pipelines of loading, filtering, grouping, joining, and aggregating data that the Pig execution engine translates into distributed processing jobs.

The [Wikipedia article on Apache Pig](https://en.wikipedia.org/wiki/Apache_Pig) explains that the platform originated at Yahoo Research around 2006 to give researchers an ad hoc way of writing and running MapReduce jobs over very large datasets, moving to the Apache Software Foundation in 2007. Its language, Pig Latin, abstracts the Java MapReduce idiom into a notation similar in spirit to SQL, and can execute the resulting jobs on MapReduce, Apache Tez, or Apache Spark.
