# Crystal

Crystal is a compiled, statically typed general-purpose programming language with syntax influenced by Ruby. It uses type inference to reduce explicit annotations and generates native code through LLVM while retaining a language model oriented toward expressive application development.

As described on [Wikipedia](https://en.wikipedia.org/wiki/Crystal_(programming_language)), work on Crystal began in June 2011 with the goal of combining the elegance and productivity of Ruby with the speed and type safety of a compiled language; the project was initially named Joy before being renamed Crystal. Its compiler, originally written in Ruby, became self-hosted in November 2013 and now compiles to native code through an LLVM backend.
