# Nim

Nim is a statically typed, compiled programming language with type inference, metaprogramming, and a syntax influenced by indentation-based languages. It commonly generates C, C++, Objective-C, or JavaScript as an intermediate target while providing direct control over memory and native interoperability.

The [Wikipedia article on Nim](https://en.wikipedia.org/wiki/Nim_(programming_language)) states that the language, led by Andreas Rumpf, was originally named Nimrod and was renamed Nim with the 0.10.2 release in December 2014. Its self-hosting compiler emits C code by default, deferring to an external C compiler for object-code generation and optimization, and its syntax uses Python-like indentation despite being statically typed.
