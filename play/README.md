# Play Framework

Play Framework is a web application framework for Java and Scala. It provides routing, HTTP request handling, asynchronous processing, template support, and an application structure intended for building server-side web applications and APIs.

As described on [Wikipedia](https://en.wikipedia.org/wiki/Play_Framework), Play Framework follows the model-view-controller pattern and was rewritten with its core in Scala starting with version 2.0, while remaining usable from Java and other languages that compile to JVM bytecode. It was heavily inspired by ASP.NET MVC, Ruby on Rails, and Django, and emphasizes developer productivity through convention over configuration and hot code reloading.
