# OCaml

OCaml is a statically typed programming language in the ML family that combines functional, imperative, and object-oriented programming. It provides type inference, algebraic data types, pattern matching, modules, and compilation to both bytecode and native code.

As described on [Wikipedia](https://en.wikipedia.org/wiki/OCaml), OCaml was created in 1996 by Xavier Leroy, Jérôme Vouillon, Damien Doligez, Didier Rémy, Ascánder Suárez, and others as an extension of the Caml dialect of ML with object-oriented features, and was renamed from Objective Caml in 2011. It grew out of work in automated theorem proving and is also used in static analysis, systems programming, and financial software, aided by a type-inferring compiler that reduces the need for manual type annotations.
