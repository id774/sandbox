# Java

Java is a statically typed, class-based general-purpose programming language whose compiled bytecode normally runs on the Java Virtual Machine. It combines automatic memory management, a large standard library, and a portable runtime model used across server, desktop, and other application domains.

The [Wikipedia article on Java](https://en.wikipedia.org/wiki/Java_(programming_language)) recounts that James Gosling, Mike Sheridan, and Patrick Naughton began the project in June 1991 under the name Oak, later renamed Java after Java coffee before Sun Microsystems released Java 1.0 in 1996. Its bytecode compilation and "write once, run anywhere" design let compiled programs run unmodified on any platform with a compatible Java virtual machine, which also manages memory through automatic garbage collection.
