# SQL

SQL is a declarative language for defining, querying, and modifying data in relational database systems. It covers data retrieval, schema definition, data manipulation, constraints, and transaction-related operations, while individual database products provide their own SQL dialects.

As described on [Wikipedia](https://en.wikipedia.org/wiki/SQL), SQL was developed at IBM in the early 1970s by Donald D. Chamberlin and Raymond F. Boyce after learning of Edgar F. Codd's relational model, giving it an advantage over older read-write APIs such as ISAM or VSAM by letting a single command operate on many records at once rather than one at a time. The standard has since been revised repeatedly to add features while remaining implemented through vendor-specific dialects.
