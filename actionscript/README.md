# ActionScript

ActionScript is an ECMAScript-derived programming language used for applications and interactive content in the Adobe Flash and AIR ecosystems. ActionScript 3 adds class-based object orientation and optional static typing and is compiled to bytecode for the ActionScript Virtual Machine.

According to the [Wikipedia article on ActionScript](https://en.wikipedia.org/wiki/ActionScript), the language was originally developed by Macromedia and later maintained by Adobe, drawing influence from HyperCard's HyperTalk scripting language and implementing the ECMAScript specification. ActionScript 3, introduced with Flash Player 9, added a just-in-time compiler that made it run substantially faster than earlier versions.
