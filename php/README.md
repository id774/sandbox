# PHP

PHP is a dynamically typed general-purpose scripting language oriented strongly toward server-side web development. It can be embedded in HTML and also supports standalone applications, object-oriented programming, namespaces, exceptions, and a large ecosystem of web libraries and frameworks.

According to [Wikipedia](https://en.wikipedia.org/wiki/PHP), Rasmus Lerdorf created PHP in 1994 by writing Common Gateway Interface programs in C to maintain his personal homepage, later extending them to work with HTML forms and databases under the name "Personal Home Page/Forms Interpreter." The name now stands for the recursive backronym "PHP: Hypertext Preprocessor," and its reference implementation, the Zend Engine, is free software that has been ported to most web servers and operating systems.
