# Haskell

Haskell is a statically typed, purely functional programming language with non-strict evaluation. It emphasizes immutable values, algebraic data types, pattern matching, type inference, higher-order functions, and type classes.

As described on [Wikipedia](https://en.wikipedia.org/wiki/Haskell), Haskell is named after the logician Haskell Curry and pioneered language features including type classes for type-safe operator overloading and monadic input/output. Its main implementation, the Glasgow Haskell Compiler, has driven successive language standards, including the Haskell 2010 revision published in July 2010.
