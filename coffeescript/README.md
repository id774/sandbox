# CoffeeScript

CoffeeScript is a programming language that compiles to JavaScript while providing a more concise syntax. It retains JavaScript's underlying runtime model and interoperability while expressing common functions, objects, and control structures with less syntax.

According to the [Wikipedia article on CoffeeScript](https://en.wikipedia.org/wiki/CoffeeScript), Jeremy Ashkenas made the first commit of the language in December 2009, describing it at the time as "the mystery language." The language draws syntactic influence from Ruby, Python, and Haskell, replacing curly-brace blocks and the `function` keyword with indentation and the `->` symbol.
