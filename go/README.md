# Go

Go is a statically typed, compiled programming language designed around simplicity, fast compilation, and straightforward concurrency. It provides garbage collection together with goroutines, channels, interfaces, and a deliberately compact language specification.

The [Wikipedia article on Go](https://en.wikipedia.org/wiki/Go_(programming_language)) states that it was designed at Google in 2007 by Robert Griesemer, Rob Pike, and Ken Thompson to improve programming productivity in an era of multicore, networked machines and large codebases, and was publicly announced in November 2009. It combines a C-like syntax with garbage collection, structural typing, and CSP-style concurrency built around goroutines and channels.
