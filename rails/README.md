# Ruby on Rails

Ruby on Rails is a full-stack web application framework written in Ruby. It follows conventions such as Model-View-Controller, convention over configuration, and Active Record to integrate routing, database access, controllers, views, and other common web application concerns.

The [Wikipedia article on Ruby on Rails](https://en.wikipedia.org/wiki/Ruby_on_Rails) states that David Heinemeier Hansson extracted the framework from his work on the project management tool Basecamp at the web company 37signals, releasing it as open source in July 2004. As a model-view-controller framework, Rails emphasizes convention over configuration, the don't-repeat-yourself principle, and the active record pattern, and its 2005 introduction popularized features such as database migrations and view scaffolding for rapid application development.
