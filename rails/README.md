# Ruby on Rails

## Overview

Ruby on Rails is a server-side web application framework written in the Ruby programming language and distributed under the MIT License. It bundles an integrated set of defaults for a web application's database layer, web service, and web pages, rather than leaving those pieces to be assembled from separate, unrelated libraries.

## History

David Heinemeier Hansson extracted Rails from his work building Basecamp, a project-management tool, for the web company 37signals — co-founded in 1999 by Jason Fried, Carlos Segura, and Ernest Kim, and later renamed Basecamp. While building Basecamp, Hansson used the then relatively obscure Ruby language to create a custom web framework, which he released separately as open-source software in July 2004, though he did not extend commit access to outside contributors until February 2005. In 2005, Google and O'Reilly recognized Hansson with a "Hacker of the Year" award for the work.

## Architecture and characteristics

Rails is a model-view-controller framework, and beyond MVC it is organized around several other named patterns: convention over configuration, under which, for instance, a model class named User is expected by default to live in a file called user.rb and to map onto a database table named users without extra setup; the don't-repeat-yourself (DRY) principle; and the active record pattern, which Rails uses to give each model class a direct mapping to a database table and to manage the underlying database access. Routing, controllers, views, database migrations, and view scaffolding are all part of one integrated framework rather than separate tools, which lets a working application skeleton — including its database schema and basic views — be produced quickly from a small amount of code.

## Ecosystem and use

As a framework written in Ruby, Rails is closely tied to the broader Ruby language and its package ecosystem, and it is frequently credited with having significantly raised Ruby's visibility after its release. Wikipedia describes Rails' 2005 debut as influential on rapid web-application development in general, pointing to its handling of database migrations and scaffolding, and notes that it went on to influence web frameworks in other languages, including Django in Python, Catalyst in Perl, Laravel, CakePHP, and Yii in PHP, Grails in Groovy, and Phoenix in Elixir. Sites reported as built on Rails include Airbnb, GitHub, Shopify, Twitch, Crunchbase, Dribbble, and Archive of Our Own.
